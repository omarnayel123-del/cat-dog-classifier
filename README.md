
# Cat vs Dog Image Classification

## Problem
Classify images as either a cat or a dog using computer vision.

## Solution
A CNN (Convolutional Neural Network) trained using TensorFlow.

## Dataset
TensorFlow Cats vs Dogs dataset (~23k images)

## Model
- CNN with 3 convolution layers
- ReLU + Sigmoid activation
- Binary classification

## Results
- Model trained successfully
- Outputs: Cat or Dog predictions
- Validation accuracy included in notebook
