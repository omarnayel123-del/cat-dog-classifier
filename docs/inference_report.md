# Inference Report

## Success Cases
The model correctly classifies most clear images of cats and dogs.

## Failure Cases
The model struggles with blurry or partially occluded images.

## Reason for Errors
- Limited training time (few epochs)
- Image quality variation in dataset

## Improvements
- Train for more epochs
- Add data augmentation
- Use transfer learning (ResNet or MobileNet)

## Conclusion
The system successfully demonstrates a working CNN-based image classification pipeline.
